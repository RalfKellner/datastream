

# Datastream Datatypes - Pricedata Time Series (Daily)

- AF: Adjustment factor
- MTBV: Market to book value
- MV: Market value
- P: Close price
- PA: Ask price
- PB: Bid price
- PH: High price
- PL: Low price
- PO: Open price
- RI: Return index
- UP: Unadjusted price
- VO: Volume
- WC03501: Common equity 

# Datastream Datatypes - Static

- DSCD: Datastream identifier
- BDATE: Base name
- ENAME: Extended company name
- EXMNEM: Datastream exchange mnemonmic 
- GEOGN: Geographical classification 
- ISIN: ISIN ID
- ISINID: Primary or secondary quote within a security
- LOC: Exchange code identifier
- PCUR: Currency of the price
- TRAC: Security type code
- TYPE: Instrument type
- WC05601: Ticker symbol 
- RIC: Reuters instrument code
- TR1: TRBC economic sector
- TR1N: TRBC economic sector name
- TR2: TRBC business sector
- TR2N: TRBC business sector name
- TR3: TRBC industry 
- TR3N: TRBC industry name

# Datastream Datatypes - Firmvariables Time Series (Monthly)

- DY: Dividen yields
- ENERDP023: CO2 equivalent emissions total 
- ENERDP024: CO2 equivalent emissions direct scope 1
- ENERDP025: CO2 equivalent emissions indirect scope 2
- ENERDP123: Estimated CO2 equivalent emissions total
- ENERDP124: CO2 estimation method (currently only latest value, check for history)
- ENERO132V: GHG emissions scope 1,2,3 to revenue in USD Millions
- ENERO52V: GHG emissions scope 1 to revenue in USD Millions
- ENERO55V: GHG emissions scope 1 to revenue in USD Millions
- ENSCORE: Environmental Pillar Score (old Refinitiv legacy scoring system 0-100)
- EPS: Earnings per share
- EPSISURDTE: EPS interim surprise announce date (check later for specific date and value retrieval) 
- EPSISURSUE: EPS interim surprise (score)
- ESGCCBDSC: Biodiversity theme score (very likely new Refinitiv legacy scoring system 0-5)
- ESGCCSC: LSEG ESG Score (new legacy)
- PE: Price earnings ratio
- TRESGS: ESG score (old legacy)
- WC01001: Net sales or revenues
- WC01250: Operating income 
- WC02003: Cash
- WC02999: Total assets 
- WC03051: Short term debt and current portion of long term debt 
- WC03251: Long term debt 
- WC03255: Total debt
- WC03501: Common equity
- WC04601: Capital expenditures 
- WC05350: Date of fiscal year and (latest value, static) 
- WC08231: Total debt in % to common equity 
- WC08301: Return on equity total % 
- WC08326: Return on assets 
- WC18198: Earnings before interest, taxes and depreciation
